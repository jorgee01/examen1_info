# Criterios generales del proyecto

## Principios de evaluación

Se valorará especialmente:

1. coherencia entre problema, datos y método;
2. justificación de las decisiones;
3. calidad del Event Log;
4. interpretación del proceso;
5. capacidad para identificar hallazgos;
6. formulación del problema de Machine Learning;
7. interpretación de métricas;
8. integración de Process Mining y Machine Learning;
9. conclusiones sustentadas en evidencia;
10. organización y reproducibilidad del trabajo.

## No se considera suficiente

- incluir capturas sin explicación;
- ejecutar algoritmos sin justificar;
- presentar únicamente métricas;
- elegir un modelo porque obtuvo el valor más alto;
- eliminar datos sin explicar el motivo;
- presentar conclusiones que no se desprenden de los resultados.
